🌿 TeeNaturals E-Commerce Platform

TeeNaturals is a modern e-commerce platform developed for a natural skincare and wellness brand. The application provides customers with a seamless shopping experience, allowing them to browse products, manage their cart, and place orders through a clean and responsive interface.

The project was built with scalability and maintainability in mind using modern React development practices.
